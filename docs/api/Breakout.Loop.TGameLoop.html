Breakout.Loop

Declaration

type TGameLoop = class(TObject)

Description

Caller owns Game and supplies measured elapsed time. No OS clock or VCL. Game must outlive this loop; destroying the loop does not free Game.

Public procedure Advance(ElapsedSeconds: Double);

Accumulates measured time and executes complete 1/120 s quanta. Time above MaxElapsedSeconds and excess complete steps are recorded as discarded; a fractional remainder survives for the next callback. Raises EArgumentOutOfRangeException on invalid elapsed time.

Parameters
ElapsedSeconds
Finite, nonnegative real elapsed seconds.
