# Delphi Breakout 1.0.1.0

This release replaces per-entity VCL controls with a single Canvas presentation and adds visual feedback while preserving the original sprites and the continuous-collision engine.

- Persistent frame buffer, cached sprites, opaque repainting, and one presentation copy.
- HUD layer 1 always above field/effects on layer 2.
- Three-part paddle with proportional caps and a stretchable striped center, ready for future size powerups.
- Block rewards: green 100, yellow 150, cyan 200, red 250, silver 400, gold 500.
- Immediate real score; displayed score advances in one-point increments at 200 points/s. Destroyed blocks fade for 250 ms without remaining colliders.
- Fixed physics at 120 Hz, independent of the 15 ms UI timer. Diagnostics separates simulation, drawing, presentation, and paint intervals.
- English README, study guide, implementation plan, reports, and generated PasDoc API reference, with English documentation paths.

The engine also includes proportional paddle angles, continuous circle/block and circle/capsule collision, deterministic seeded generation, and explicit lifecycle states developed in earlier stages.

- `SHA256SUMS.txt` and `release-manifest.json`: checksums, binary versions/architectures, and source revision.

Extract a game archive and run Breakout.exe; embedded sprites require no separate asset directory. Move with the mouse; click/Space launches, F2 restarts, F3 pauses, F10 shows diagnostics, and paused F1 steps when diagnostics is open. Focus loss pauses and requires F3 to resume.

For API browsing, extract the documentation archive and open `docs/api/index.html`. GitHub's source view does not render this HTML as a hosted site.

## Validation and scope

The original E4 validation built main/console in Win32/Win64 Debug/Release and passed 191 console cases/configuration plus 47 VCL/bitmap checks. After the final 5 ms adjustment, the main Win64 Release, runner Win32 Debug, and console Win64 Debug were rebuilt; 191 console and 47 VCL checks passed again. Both supplied Release binaries report file/product version 1.0.1.0. PasDoc generation completed without warnings; local documentation links/anchors were checked.

The historical 15 ms timer sample produced about 56–57 paintings/s on the reference machine. This is not a constant-FPS or monitor-sync guarantee. Real DPI transitions, multiple monitors, and prolonged evaluation remain E6 work. The window is fixed; menus, fullscreen, powerup mechanics, and endless template-based levels remain planned. E5 is the next implementation stage.
