function SweepCircleRect(CX, CY, Radius, VX, VY, MaxTime: Double; const Rect: TPhysicsRect; out Hit: TCircleHit): Boolean;

Sweeps a circle against a rectangle over [0, MaxTime]. Tests four face segments and four circular corner arcs, including initial overlap.

Parameters
CX
Circle center X in logical units.
CY
Circle center Y in logical units.
Radius
Positive circle radius.
VX
Horizontal velocity in units per second.
VY
Vertical velocity in units per second.
MaxTime
Nonnegative interval in seconds.
Rect
Static solid bounds.
Hit
Earliest inward contact, reset to zero if none is found.
Returns

True when contact is found in the interval.

function SweepCirclePaddle(CX, CY, Radius, VX, VY, MaxTime: Double; const Rect: TPhysicsRect; out Hit: TCircleHit): Boolean;

Sweeps against a horizontal capsule with cap radius half its height. Reduces to the center segment dilated by ball radius plus cap radius. Coordinates, velocity, time and Hit follow SweepCircleRect.

procedure ReflectVelocity(var VX, VY: Double; NX, NY: Double);

Applies v := v - 2*dot(v,n)*n only when approaching the surface. NX/NY must form an outward unit normal; separating velocity is unchanged.
