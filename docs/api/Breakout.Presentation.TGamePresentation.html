Declaration

type TGamePresentation = class(TObject)

Description

Owns a copied snapshot, bounded fade slots and a displayed score. Sync/Advance mutate presentation; painting only reads. No VCL or OS clock.

Public procedure Advance(ElapsedSeconds: Double; Frozen: Boolean);

Advances fade ages and score using elapsed time, with arithmetic catch-up bounded by the target. The caller applies any elapsed cap. Raises EArgumentOutOfRangeException on invalid elapsed time.

Parameters
ElapsedSeconds
Finite, nonnegative elapsed seconds.
Frozen
When True, neither animation nor score advances.
