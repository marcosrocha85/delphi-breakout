Public procedure Execute(Command: TGameCommand);

Applies one lifecycle command. Launch starts Ready, or loads the next board in Ready after LevelComplete while preserving lives/score. Victory requires Restart, which resets the whole seeded match. DebugStep advances once only when paused; it can change state after a loss or final brick.

Public procedure MovePaddle(CenterX: Double; AllowPaused: Boolean = False);

Moves the paddle in Ready/Playing and carries the ready ball. Paused diagnostics may opt in to reposition only the paddle between debug steps; the ball and simulation remain frozen.

Parameters
CenterX
Requested center in logical units, clamped to the field.
AllowPaused

Public procedure Step;

Advances one FixedDeltaSeconds quantum only while Playing. Earliest impacts consume time, reflect velocity and continue the remaining interval, up to MaxImpactsPerStep.
